All tokens are built on **Tari** (Monero's Layer 2):

| Feature | Benefit |
|---------|---------|
| **Stealth Addresses** | Nobody knows who owns what |
| **Ring Signatures** | Transactions are mixed and anonymous |
| **Confidential Amounts** | Values are hidden |
| **Private by Default** | No opt-in required |
