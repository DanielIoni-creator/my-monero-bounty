# 💰 Spiccioli in Monero
### Micro-bounties for everyone — even the poorest can contribute

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Monero](https://img.shields.io/badge/Payments-Monero-orange)](https://www.getmonero.org/)

## 💡 The Philosophy

**"Not how much you give, but how many give it."**

This project pays **micro-bounties in Monero (XMR)** for small fixes:

- Typo corrections: **0.0005 XMR** (≈ €0.10)
- CSS fixes: **0.001 XMR** (≈ €0.20)  
- Unit tests: **0.003 XMR** (≈ €0.60)
- Small features: **0.01 XMR** (≈ €2.00)

**Why?** Because open source should be accessible to *everyone* — including contributors who:
- Can't afford to work for free
- Don't have a bank account
- Live in countries with financial restrictions
- Just want to earn their coffee ☕

## 🚀 How It Works

1. **Browse** the Issues with 💰 labels
2. **Claim** by commenting "I'll take this!"
3. **Fix** the problem and open a Pull Request
4. **Get paid** in Monero within 24h of merge

## 🔒 Privacy First

- **No KYC** - We never ask for ID, passport, or bank details
- **No personal data** - Only your Monero address is needed
- **Anonymous by default** - Your Monero address can't be traced back to you
- **Private payments** - Monero uses stealth addresses for every transaction

### What's Public
- ✅ The amount paid for each issue (transparency)
- ❌ Who received it (privacy)
- ❌ Who sent it (privacy)
